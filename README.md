# Italify

**A jump start for your italics.**

Italify is a purely geometry-based approach for *really good* synthetic obliques. No AI, no funny stuff.

Runs in [Glyphs](https://glyphsapp.com).

- **Website & interactive demos:** [sebastiancarewe.com/italify](https://www.sebastiancarewe.com/italify)
- **Licensing:** [sebastiancarewe.com/italify/buy](https://www.sebastiancarewe.com/italify/buy)
- **Handbook:** [sebastiancarewe.com/italify/handbook](https://www.sebastiancarewe.com/italify/handbook)
- **Python API:** [sebastiancarewe.com/italify/python-api](https://www.sebastiancarewe.com/italify/python-api)

## Install

1. Open up the plugin manager in your preferred Glyphs version. Search for Italify and install it.
2. After relaunching you have all of Italify: the Italify entry in the Filter menu, the Italify Tagger in the Edit View toolbar (shortcut C), and the Italify Groups palette in the Window sidebar.

Italify is automatically updated through the plugin manager.

Italify requires **Glyphs 3.2 or later.**
