# Italify

**A jump start for your italics.** Italify is a [Glyphs](https://glyphsapp.com)
plugin that algorithmically corrects obliques: it fixes the curve
deformation, diagonal contrast shifts and anchor drift a mechanical slant
introduces, so a slanted master becomes a starting point you can actually
work with.

- **Website & interactive demos:** [sebastiancarewe.com/italify](https://www.sebastiancarewe.com/italify)
- **Pricing:** [sebastiancarewe.com/italify/pricing](https://www.sebastiancarewe.com/italify/pricing)
- **Handbook:** [sebastiancarewe.com/italify/handbook](https://www.sebastiancarewe.com/italify/handbook)
- **Python API:** [sebastiancarewe.com/italify/python-api](https://www.sebastiancarewe.com/italify/python-api)

## Install

1. Download the latest **Italify.glyphsPlugin.zip** from the
   [Releases page](https://github.com/eweracs/Italify/releases/latest)
   and unzip it.
2. Double-click `Italify.glyphsPlugin` — Glyphs installs it into your
   Plugins folder.
3. Relaunch Glyphs. You'll find *Italify* in the Filter menu, the
   *Italify Tagger* in the toolbar and the *Italify Groups* palette in
   the sidebar.

Italify requires **Glyphs 3.2 or later**.
